# Cara International School – Admission Enquiry Webform

A public admission enquiry webform developed for the **Cara International School School Management System** project.

The form is connected to **Zoho CRM** and allows prospective parents to submit admission enquiries directly into the CRM as leads.

## Features

* Admission enquiry form
* First Name and Last Name
* Email and Phone
* Company/School information
* Enquiry description
* Zoho CRM Lead integration
* Custom thank-you message after submission
* Publicly accessible webform using GitHub Pages

## Technologies Used

* HTML
* CSS
* JavaScript
* Zoho CRM Webforms
* GitHub Pages

## Project Purpose

This webform is part of a School Management System built using **Zoho CRM and Zoho Creator**. It provides a public-facing entry point for admission enquiries while Zoho CRM manages the submitted leads.
